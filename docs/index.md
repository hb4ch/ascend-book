# 昇腾平台技术实战 · 导读

> 面向实操型工程师的昇腾全栈技术书。以 CANN 开源仓源码为第一手资料，逐层拆解昇腾平台。
> 全书目标：（1）建立全局认知；（2）掌握算子实现与性能优化；（3）深入底层 runtime/驱动/工具链；（4）详解 PTO 等现代编译后端。

## 为什么需要这本书

昇腾（Ascend）在训练侧已大量装备 910B/910C（Atlas A2/A3），950 系列（A5）正在进入超节点（SuperPod）与数据中心；但开源生态的语言——CANN 被拆成了几十个仓，官方文档分散、术语不统一、样例碎片化。一个实操工程师面对的最大痛点是：**知道 API 名字，却不知道背后发生了什么**；能调通样例，却无法在算子性能不达标时下手优化。

这本书把十个核心开源仓当作「标本」，按真实执行链路排序，带读者把每一层翻开看。

## 读者对象与前置要求

- **谁适合读**：有 C/C++ 与深度学习基础、想搞懂昇腾的工程师。
- **不需要**：昇腾经验、NPU 真机。
- **需要的**：一台 x86/鲲鹏 Linux 机器（读源码/跑 CPU 仿真足够）。

## 两条阅读路径

- **上手线**（想先跑通、建立信心）：第1章 → 第9章（API 选择）→ 第10章核心能力 → 第14章实战 → 附录A 环境搭建。
- **深度线**（想做极致性能/底层/编译）：第1章 → 第2章（硬件）→ 第二编全部（runtime/驱动/内存）→ 第四编（性能）→ 第六编（PTO/PyPTO）。

## 全书写法约定

- 一切论断以**源码/仓内文档**为准，正文用 `📦 源码:` 与 `📄 资料:` 行内标注精确路径。见 [写作规范（站内版）](./附录/appE-style.md) 与根目录 `STYLEGUIDE.md`。
- 代码运行性分级：

| 标记 | 含义 |
|---|---|
| `[可在 NPU 运行]` | 仓内已验证样例，读者在真实环境可直接跑 |
| `[可用 CPU-SIM 运行]` | 本机 CPU Simulator 可运行（如 pto-isa CPU-SIM） |
| `[需真机验证]` | 本机无 NPU 无法真机执行，请按附录A 准备环境验证；含义正确性由源码保证 |
| `[示意代码]` | 简化的原理示意，不保证可编译运行 |

> 本机（编写环境）无 NPU 硬件、未安装 CANN/NPU-Simulator，故第二~四编的 `[需真机验证]` 内容由**读者在拥有硬件环境下自行验证**，每段均给出验证步骤。
